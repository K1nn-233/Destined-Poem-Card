使用说明与字段说明

快速上手

  1. 导入 places.yaml、edges.yaml；如有独立坐标文件，再导入 markers。
  2. 查看模式下点击地点或连线，可在右侧查看详情和异常提示。
  3. 点击顶部“编辑模式：关”开启编辑。开启后可直接拖动地图点修改位置。
  4. 点击“新增地点”后在地图上落点。若当前选中了一个地点，新地点会默认归到它下面。
  5. 点击“新建连线”后依次点击两个地理地点；选中地点或连线后，可在右侧编辑或删除。
  6. 修改完成后先点“暂存”保存在当前浏览器，或点“导出文件”保存数据文件。

地点字段

id
稳定标识，用于数据引用；建议保持不变，不要使用外部 marker 编号。
name
界面和文本中展示的地点名称。
parent
地点所属的上级地点。只表达“位于/包含于”，不表达能否通行。
is_geographic
是否为地理点。真实地点写“是”；展示标记、事件图标等写“否”。
is_waypoint
是否为路线中的中继点，例如关口、驿站或航线转折点。
keywords
额外匹配词，帮助识别当前地点，不用于展示。
labels
简短标签，例如“港口”“高危区域”“贸易中心”。
importance
输出优先级，建议 3 为核心地点，2 为常用地点，1 为补充地点。
description
地点简述和详细说明；路线天数不要写在这里。
marker_id / marker
地图坐标和展示信息。拖动地图点时会更新这里的数据。

连线字段

from / to
连线两端的地理地点，只引用地点标识，不是坐标或显示名。
bidirectional
是否可以双向通行。单向传送、季风航线等可设为否。
transport
交通方式，例如商队、徒步、船只、传送；写“不适用”表示仅描述相邻或阻隔。
days
单程耗时天数；未知可留空。
terrain
经过的主要地形，例如平原、森林、河流、海洋。
direction
方位提示，例如东西、南北、西-东。
importance
路线展示优先级，3 为骨干路线，2 为常规路线，1 为局部路线。

容易混淆的规则

  • 父级关系不是道路关系：地点属于某区域，不代表它与区域内其他地点直接相通。
  • 只有连线才表示路线或地理连接。
  • 删除地点会同时删除与它直接关联的连线；有子地点的地点不能直接删除。
  • “暂存”只保存到当前浏览器；要带走或提交修改，请使用“导出文件”。

提示说明

什么是地理点：is_geographic: true 表示实际地理地点，例如国家、城市、村落、港口、山口或道路中继点，可以参与连线和路线计算。

is_geographic: false 表示说明性或展示性对象，例如事件标记、商船、图标说明。它可以有位置和描述，但不应作为连线起点、终点或路线中继点。

判断方法：角色能否“从这里出发或抵达这里”？能，通常就是地理点；只是用于说明或展示，就应设为非地理点。

  • 添加地点时，如果是世界书已有内容，确定地点名称即可；如果没有，则需要填写简述和详述。
  • 添加边时，请填写默认通行方式和时间，以及会经过的地形，暂时不要用分段通行方式功能。
